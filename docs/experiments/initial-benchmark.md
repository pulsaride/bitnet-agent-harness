# Initial benchmark campaign

Campaign: `2026-11-21T19-58-11-429Z`

The campaign recorded one observation for each of ten seeded maintenance tasks using the bounded BitNet action loop.

## Results

- Observations: 10
- Accepted repairs: 0
- External task evaluators run: 0
- Recorded failure class: `verification`

The observations used two endpoint configurations and therefore do not form a fully frozen comparison. No result was accepted from model output alone; completion requires independent evaluator evidence.

## Interpretation

The campaign measures one local harness/model run. It does not establish task quality, general model capability, or comparative harness performance. A controlled follow-up should use one endpoint configuration, execute task evaluators outside model control, and retain telemetry, diff hashes, and test exit status.

Raw campaign records are local evidence and are excluded from the published package.
